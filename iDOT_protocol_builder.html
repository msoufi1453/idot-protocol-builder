How to use
  • Sheet: header row ,1A,1B,… (column number + row letter; A1 also works), then one row per liquid with volumes in µL. Empty cells and zeros are skipped. Comma, semicolon or tab separated.
  • Liquid names become <initials>_<name> with special characters replaced by _: Hepes-KOH, pH 8.0 → MoS_Hepes_KOH_pH_8_0.
  • Each liquid gets its own source well, filled column by column (A1, B1, … H1, A2, …). A liquid that does not fit in one source well (80 µL including 5 % extra) is split over several.
  • Liquid classes: when the iDOT software sees a liquid name that is new to its library, it asks for a liquid class. Pick the class that matches the liquid (for water and water-like buffers: 0.95) and let it save the liquid; it will not ask again for that name.
  • Every file is checked before saving: it is re-read and each well, volume and source well is compared with the sheet.
